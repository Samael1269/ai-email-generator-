# AI Email Reply Generator

A simple AI-powered email reply generator built using HTML, CSS, JavaScript, PHP, and DeepSeek API.

## Features

- Paste an email or message
- Choose reply tone
- Generate AI reply
- Copy generated reply
- Regenerate reply
- Clear form

## Tech Stack

- HTML
- CSS
- JavaScript
- PHP
- DeepSeek API

## Setup

1. Make sure to download xampp on your machine
2. Clone this repository.
3. Place the project inside your XAMPP `htdocs` folder.
4. Start Apache in XAMPP.
5. Create a `.env` file in the project root.
6. Add your DeepSeek API key:

```env
DEEPSEEK_API_KEY=your_api_key_here
